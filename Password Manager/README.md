# Password Manager

A beginner-friendly Python password manager with:
- Master password authentication
- Fernet encryption for stored credentials
- Secure random password generation
- SQLite database
- Add, view, search, update and delete credentials

## Requirements
Python 3.9+

Install dependency:
`pip install cryptography`

## Run
`python main.py`

On first run, create a master password. On later runs, use the same master password.
