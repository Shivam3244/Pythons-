# Quiz Game

A simple Python Quiz Game project.

## Features
- Multiple-choice questions
- Questions stored in a JSON file
- Random question order
- Automatic score calculation
- Percentage/result display
- Easy-to-edit question database

## Requirements
- Python 3.9 or later
- No external libraries required

## How to Run
1. Open a terminal in this folder.
2. Run:
   `python main.py`
3. Select **Start Quiz**.

## Project Structure
- `main.py` - Main application
- `questions.json` - Quiz questions and answers
- `README.md` - Project documentation
